# moemente.github.io

My personal game dev portfolio — a collection of Unity projects I've built, ranging from a top-down action shooter to a recreation of the first dungeon in Zelda.

## Projects

### The Retriever
A top-down action shooter where you rescue dogs from Evil Inc. Built in Unity with a full guard AI system, noise mechanics, and cutscenes. Developed as part of a 4-person team.

### Zelda
A faithful recreation of the first dungeon from the original NES Legend of Zelda, with a custom level designed around a new addition to the game — frost boots.

### Zombie Project
A Unity zombie survival game built in 2 weeks (My intro to game development).
